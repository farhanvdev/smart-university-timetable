# CampusFlow — Smart University Timetable Generator

Full-stack academic timetable generator using React + Vite, FastAPI, SQLite, Constraint Satisfaction (MRV/backtracking), Simulated Annealing, and Tabu Search.

## Expanded demo dataset

The project includes a fictional, synthetic dataset (not downloaded from an external source):

- 30 teachers
- 20 subjects
- 15 classrooms/labs (11 classrooms + 4 labs)
- 10 student batches
- 60 teacher-subject eligibility links
- Teacher availability by weekday and period
- 250 weekly class assignments are generated by the solver

CSV copies are in the `dataset/` folder for inspection and project-report use. The backend creates the same data automatically on first startup with a fresh database.

## Run on macOS

### Important when upgrading an existing installation

Stop the old backend with `Ctrl + C`. The previous SQLite database contains the old 6/6/5/2 sample records. To load the expanded sample data, delete `backend/timetable.db` once before restarting the backend. This removes old generated demo timetables too. Do not delete it if you need to keep old data.

### Backend (Terminal 1)

```bash
cd backend
source .venv/bin/activate
python -m pip install -r requirements.txt
uvicorn app.main:app --reload
```

API docs: http://127.0.0.1:8000/docs

### Frontend (Terminal 2)

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173

## Algorithms

1. CSP uses MRV ordering and backtracking to assign eligible teachers, available periods, and suitable rooms while preventing teacher, room, and batch clashes.
2. Simulated Annealing explores valid neighboring timetables and minimizes soft-constraint penalties.
3. Tabu Search uses a short-term tabu list to discourage cycling through recent moves.

This is a college-project MVP, not a production university ERP. The sample records are fictional and should be replaced with authorized university data for real deployment.
